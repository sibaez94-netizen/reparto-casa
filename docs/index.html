Los minutos son una estimación, y de ellos sale el % de cada tarea. Si a alguno le parece que una tarea lleva más o menos tiempo del que pone, se cambia aquí y todo el reparto se recalcula solo. Discutir sobre minutos es más fácil que discutir sobre porcentajes.
Lo que se marcó cada semana, para mirarlo juntos y ajustar. Cuenta quien marca la tarea, no a quien estaba asignada.
